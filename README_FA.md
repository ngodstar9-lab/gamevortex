# GameVortex

وب‌سایت فارسی معرفی بازی با طراحی تیره و واکنش‌گرا.

## امکانات سایت
- کتابخانه ۸ بازی با جست‌وجو و دسته‌بندی
- صفحه جزئیات بازی و لینک‌های رسمی
- علاقه‌مندی‌ها (ذخیره محلی در مرورگر)
- پیشنهاد تصادفی بازی
- پنل مدیریت با ورود Supabase
- افزودن، ویرایش، حذف و انتشار/پیش‌نویس بازی‌ها
- همگام‌سازی بازی‌های منتشرشده بین پنل و سایت عمومی

## فایل‌های مهم
- `index.html`, `style.css`, `script.js`: سایت عمومی
- `admin.html`, `admin.css`, `admin.js`: پنل مدیریت
- `supabase-config.js`: محل تنظیم URL و کلید عمومی پروژه اختصاصی GameVortex
- `supabase-setup.sql`: ساخت جدول‌ها و سیاست‌های امنیتی
- `README_FA.md`: راهنما

## راه‌اندازی پنل مدیریت
**مهم:** برای مستقل ماندن GameVortex، یک پروژه Supabase جدید مخصوص همین سایت بساز؛ از پروژه سایت قرآن استفاده نکن.

1. در داشبورد Supabase یک پروژه جدید بساز.
2. در SQL Editor، محتوای فایل `supabase-setup.sql` را اجرا کن.
3. در Authentication > Users یک کاربر مدیر بساز.
4. UUID همان کاربر را کپی کن و در SQL Editor این دستور را با UUID واقعی اجرا کن:
   `insert into public.admin_users (user_id) values ('UUID-اینجا');`
5. از بخش Project Settings > API، Project URL و کلید عمومی `anon` یا `publishable` را بردار.
6. این دو مقدار را در فایل `supabase-config.js` وارد کن و در GitHub ذخیره کن. فقط کلید عمومی مجاز است؛ **هرگز service_role را در سایت قرار نده.**
7. پس از انتشار مجدد GitHub Pages، وارد `admin.html` شو و با ایمیل و رمز مدیر وارد شو.

آدرس پنل: `https://ngodstar9-lab.github.io/gamevortex/admin.html`

## انتشار
در مخزن GitHub، Settings > Pages را باز کن. منبع را روی Deploy from a branch، شاخه را `main` و پوشه را `/(root)` انتخاب کن. بعد از اتمام انتشار، سایت در آدرس زیر در دسترس خواهد بود:

`https://ngodstar9-lab.github.io/gamevortex/`

## نکات امنیتی
- هیچ کلید service_role در فایل‌های فرانت‌اند قرار داده نشده.
- مجوز مدیران از جدول محدودشده `admin_users` و سیاست‌های RLS بررسی می‌شود.
- کاربران عمومی فقط بازی‌های منتشرشده را می‌خوانند.
- علاقه‌مندی‌ها در حافظه محلی مرورگر همان بازدیدکننده ذخیره می‌شوند.
