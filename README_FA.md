# GameVortex

وب‌سایت فارسی معرفی بازی با طراحی تیره، واکنش‌گرا و پنل مدیریت مستقل.

## امکانات سایت عمومی
- کتابخانه بازی با جست‌وجوی زنده و دسته‌بندی
- مرتب‌سازی پیشنهادی، الفبایی و جدیدترین
- علاقه‌مندی‌ها با ذخیره محلی در مرورگر
- پیشنهاد تصادفی بازی
- پنجره جزئیات و لینک رسمی بازی‌ها
- نمایش تصویر جلد و پلتفرم‌ها در صورت تعریف مدیر
- انتخاب بازی ویژه از پنل و نمایش آن در صفحه اصلی
- پیام اطلاع‌رسانی قابل مدیریت از پنل
- نصب به‌صورت وب‌اپ (PWA) در مرورگرهای پشتیبانی‌شده
- پوسته اصلی قابل استفاده به‌صورت آفلاین پس از اولین بارگذاری موفق
- صفحه خطای اختصاصی 404

## امکانات پنل مدیریت
- ورود با Supabase Auth و بررسی UID در جدول admin_users
- افزودن، ویرایش، کپی، انتشار، پیش‌نویس و حذف بازی
- انتخاب بازی ویژه صفحه اصلی
- ثبت لینک تصویر جلد HTTPS و پلتفرم‌ها
- جست‌وجو و فیلتر بر اساس نام، دسته و وضعیت
- خروجی CSV و پشتیبان JSON
- مدیریت پیام اطلاع‌رسانی صفحه اصلی
- آمار کتابخانه و زمان آخرین تازه‌سازی
- کنترل‌های دسترسی با Row Level Security

## فایل‌ها
- `index.html`, `style.css`, `script.js`: سایت عمومی
- `admin.html`, `admin.css`, `admin.js`: پنل مدیریت
- `supabase-config.js`: Project URL و کلید عمومی Publishable
- `supabase-setup.sql`: ساخت اولیه دیتابیس
- `supabase-upgrade.sql`: ارتقای امن جدول‌ها برای امکانات جدید
- `manifest.webmanifest`, `sw.js`, `favicon.svg`: وب‌اپ و قابلیت آفلاین
- `404.html`: صفحه خطای اختصاصی

## راه‌اندازی دیتابیس
1. در Supabase یک پروژه جداگانه مخصوص GameVortex داشته باش؛ از پروژه نور قرآن استفاده نکن.
2. اسکریپت پایه `supabase-setup.sql` باید قبلاً اجرا شده باشد.
3. پس از دریافت نسخه جدید، اسکریپت `supabase-upgrade.sql` را از ابتدا تا انتها در SQL Editor اجرا کن. این اسکریپت اطلاعات بازی‌ها و مدیران فعلی را حذف نمی‌کند.
4. مدیر باید در Authentication > Users وجود داشته باشد و UID همان حساب در `public.admin_users` ثبت شده باشد.
5. در `supabase-config.js` آدرس پروژه و کلید عمومی Publishable را قرار بده.
6. پنل مدیریت را در `https://ngodstar9-lab.github.io/gamevortex/admin.html` باز کن.

## انتشار
در مخزن GitHub، Settings > Pages را روی Deploy from a branch، شاخه `main` و پوشه `/(root)` قرار بده.

- سایت: `https://ngodstar9-lab.github.io/gamevortex/`
- پنل: `https://ngodstar9-lab.github.io/gamevortex/admin.html`

## نکات امنیتی و محدودیت‌ها
- کلید Secret یا service_role نباید در فایل‌های سایت قرار بگیرد.
- کاربران ناشناس فقط بازی‌های منتشرشده و متن اعلان عمومی را می‌خوانند.
- فقط UIDهایی که در `admin_users` ثبت شده‌اند می‌توانند مدیریت کنند.
- اعطای دسترسی مدیر جدید فقط از طریق SQL Editor و توسط مالک پروژه انجام شود.
- علاقه‌مندی‌ها روی همان مرورگر ذخیره می‌شوند و بین دستگاه‌ها همگام نیستند.
- قابلیت آفلاین، پوسته و فایل‌های اصلی را نگه می‌دارد؛ ورود، دیتابیس و ذخیره تغییرات همچنان به اینترنت نیاز دارند.
