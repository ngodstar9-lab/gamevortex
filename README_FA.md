# GameVortex
سایت گیمینگ فارسی با طراحی واکنش‌گرا و تم مشکی/قرمز.

## فایل‌ها
- `index.html`: ساختار صفحه
- `style.css`: طراحی و استایل
- `script.js`: جست‌وجو، فیلتر دسته‌بندی و منوی موبایل

## انتشار با GitHub Pages
1. در مخزن به Settings > Pages برو.
2. گزینه Deploy from a branch را انتخاب کن.
3. Branch را روی main و پوشه را روی /(root) بگذار و Save را بزن.
4. پس از پایان انتشار، آدرس سایت در همان بخش نمایش داده می‌شود.

این نسخه فعلاً استاتیک است؛ پنل مدیریت، ورود کاربران و پایگاه داده هنوز پیاده‌سازی نشده‌اند.
