# GameVortex

وب‌سایت فارسی معرفی بازی با طراحی تیره، واکنش‌گرا و هویت بصری مشکی/قرمز.

## امکانات این نسخه
- صفحه اصلی و بخش معرفی GameVortex
- کتابخانه ۸ بازی با دسته‌بندی و جست‌وجوی زنده
- فیلتر سبک بازی‌ها
- پنجره جزئیات و لینک صفحه رسمی بازی‌ها
- ذخیره علاقه‌مندی‌ها در مرورگر کاربر
- پیشنهاد تصادفی بازی از میان نتایج
- منوی موبایل و طراحی واکنش‌گرا
- بدون نیاز به نصب پکیج یا سرور؛ فقط HTML، CSS و JavaScript

## فایل‌ها
- `index.html`: ساختار و محتوای سایت
- `style.css`: ظاهر، انیمیشن‌ها و نسخه موبایل
- `script.js`: جست‌وجو، فیلتر، علاقه‌مندی‌ها و پنجره جزئیات

## انتشار با GitHub Pages
1. در مخزن GitHub وارد **Settings > Pages** شو.
2. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کن.
3. Branch را روی `main` و پوشه را روی `/(root)` قرار بده و **Save** را بزن.
4. پس از پایان انتشار، آدرس عمومی سایت در همان صفحه نمایش داده می‌شود.

## نکته مهم
این نسخه یک سایت استاتیک و آماده انتشار است. علاقه‌مندی‌ها در مرورگر هر بازدیدکننده ذخیره می‌شوند. پنل مدیریت امن و دیتابیس آنلاین هنوز به پروژه متصل نشده‌اند؛ برای این بخش باید یک پروژه Supabase جداگانه مخصوص GameVortex ساخته و تنظیم شود. اطلاعات و تنظیمات سایت نور قرآن در این پروژه استفاده نشده‌اند.
