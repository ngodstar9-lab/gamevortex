# GameVortex

وب‌سایت فارسی معرفی بازی با طراحی تیره، واکنش‌گرا و پنل مدیریت متصل به Supabase.

## امکانات سایت عمومی
- کتابخانه بازی با جست‌وجوی زنده و دسته‌بندی
- مرتب‌سازی پیشنهادی، الفبایی و جدیدترین
- فهرست علاقه‌مندی‌ها با ذخیره محلی در مرورگر
- پیشنهاد تصادفی بازی
- جزئیات بازی و لینک رسمی
- نمایش تصویر جلد و پلتفرم‌ها (در صورت تعریف مدیر)
- نمایش بازی ویژه انتخاب‌شده از پنل
- پیام اطلاع‌رسانی قابل مدیریت از پنل
- نمایش نسخه جایگزین در صورت قطع ارتباط دیتابیس

## امکانات پنل مدیریت
- ورود با Supabase Auth و بررسی UID در جدول admin_users
- افزودن، ویرایش، کپی، انتشار، پیش‌نویس و حذف بازی
- تعیین بازی ویژه برای صفحه اصلی
- ثبت لینک جلد HTTPS و پلتفرم‌ها
- جست‌وجو و فیلتر کتابخانه در پنل
- خروجی CSV و پشتیبان JSON از بازی‌ها
- مدیریت پیام اطلاع‌رسانی صفحه اصلی
- آمار بازی‌ها و زمان آخرین تازه‌سازی

## فایل‌ها
- `index.html`, `style.css`, `script.js`: سایت عمومی
- `admin.html`, `admin.css`, `admin.js`: پنل مدیریت
- `supabase-config.js`: آدرس پروژه و کلید عمومی Publishable
- `supabase-setup.sql`: ساخت اولیه دیتابیس
- `supabase-upgrade.sql`: ارتقای جدول‌ها برای امکانات جدید (اطلاعات را حذف نمی‌کند)

## راه‌اندازی و ارتقا
1. مخزن GitHub را از طریق GitHub Pages منتشر کن.
2. پروژه Supabase باید جدا از پروژه سایت نور قرآن باشد.
3. اگر جدول‌های اولیه ساخته شده‌اند، در SQL Editor فایل `supabase-upgrade.sql` را اجرا کن.
4. حساب مدیر باید در Authentication > Users وجود داشته باشد و UID همان حساب در جدول `admin_users` ثبت شده باشد.
5. `supabase-config.js` باید Project URL و کلید عمومی `Publishable` را داشته باشد.
6. پنل: `https://ngodstar9-lab.github.io/gamevortex/admin.html`

## امنیت
- کلید Secret یا service_role هرگز در سایت قرار نمی‌گیرد.
- مدیریت بر اساس Auth و سیاست‌های Row Level Security انجام می‌شود.
- کاربران ناشناس فقط بازی‌های منتشرشده و تنظیمات اعلان مجاز را می‌خوانند.
- مجوز مدیر باید به‌صورت دستی در جدول admin_users اعطا شود.
- تصویر جلد فقط از نشانی HTTPS استفاده می‌کند.

## نکته
علاقه‌مندی‌ها در مرورگر بازدیدکننده ذخیره می‌شوند و بین دستگاه‌ها همگام نیستند. پنل مدیریت عمومی نیست و فقط حساب‌های ثبت‌شده در admin_users اجازه مدیریت دارند.
